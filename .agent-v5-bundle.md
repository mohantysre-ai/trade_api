# V5 Trade System Suite

This bundle groups the core operational agents for the trade API repository.

## Included agents

1. Senior engineer
   - [.agent.md](.agent.md)
   - General architecture, correctness, safety, and validation discipline

2. V5 safety auditor
   - [.agent-v5-safety.md](.agent-v5-safety.md)
   - Focused on stale writes, safety guards, live-state authority, rotation, and session integrity

3. V5 performance auditor
   - [.agent-v5-performance.md](.agent-v5-performance.md)
   - Focused on hot paths, concurrent load, duplicate refresh prevention, and bounded runtime behavior

4. Release gate reviewer
   - [.agent-release-gate.md](.agent-release-gate.md)
   - Final go / no-go decision support for shipping decisions

## Recommended usage

Use the most specific agent for the task:

- Senior engineer: broad bug-fix or system work
- V5 safety auditor: stale-write, state authority, session integrity, rotation and lock safety
- V5 performance auditor: concurrency, refresh storms, optimization validation, hot-path load checks
- Release gate reviewer: final readiness / deployment decision support

## Example combined workflow

1. Use the V5 safety auditor to find correctness or stale-write issues.
2. Use the performance auditor to validate concurrency and load behavior.
3. Use the release gate reviewer to decide whether the repo is deployable.
4. Use the senior engineer agent for final implementation and regression work.

## Principle

The repository’s safest default posture is:

- challenge assumptions
- protect live vs durable state boundaries
- verify with fresh evidence
- reject silent stale-state success
- ship only when correctness, safety, and runtime validation are in place
